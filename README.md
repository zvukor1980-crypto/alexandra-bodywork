# Alexandra Bodywork

Static bilingual website for Alexandra Bodywork in Haifa, Hadar.

Production: https://bodywork.world/

No build step or dependencies. Vercel publishes the main branch automatically.

Original export: Sites commit 4d458dd713452ca46ae4de232af6ce4249bc0ee6. Design and assets preserved; domain metadata, language descriptions and page-exit audio handling updated for migration.

Website reviews use the server-only Supabase Edge API documented in [backend/README.md](backend/README.md). The frontend remains buildless HTML/CSS/JS.
